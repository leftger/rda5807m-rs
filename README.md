# RDA5807M Rust Driver

A `no_std` Rust driver for the RDA5807M FM radio receiver, generated from a YAML register manifest with [`device-driver`](https://crates.io/crates/device-driver).

## Installation

Add this to your `Cargo.toml`:

```toml
[dependencies]
rda5807m-rs = "0.1"
```
